# SafeServe

System for restaurant managing

## Setup

```bash
poetry install
poetry run python manage.py migrate
poetry run python manage.py runserver
```

## Endpoints

- `/` — Health check
- `/swagger/` — Swagger UI
- `/redoc/` — ReDoc
- `/schema/` — OpenAPI schema
- `/admin-k9Xm4pR2/` — Django Admin
